# Gears Inside v2 "Workshop" Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Ship the four v2 pillars — living home scene, gear-playground Bench tab with 12 challenges, live Model Hall collection wall, Repair Corner — plus the nav rework, new badges and the poster flip fix.

**Architecture:** All new UI is SwiftUI Canvas/TimelineView (iOS 15.6-safe). The bench is a pure-value mesh solver (`BenchModels`) consumed by one Canvas view; the hall reuses each `MechanismSpec.draw` at mini scale; repair guides are static content structs. Persistence stays in `CogStore` (UserDefaults JSON, tolerant decoding).

**Tech Stack:** Swift 5 / SwiftUI, Canvas + TimelineView, UserDefaults; art via `art_src/gen.swift` (CoreGraphics, deterministic).

- Custom components only: no SF Symbols, no emoji, no system Slider/TabView.
- English (US) copy only; app name/version untouched (1.0 build 1).

- Verification = clean `xcodebuild` (sim Debug + device Release) + code review + on-sim screenshots; no XCTest target exists.

### Task 2: Bench mesh solver

**Files:**
- Create: `Gears Inside/BenchModels.swift`

**Interfaces:**
- Produces:
  - `enum BenchGearSize: String, CaseIterable, Codable` — `.small`(8t, r 1.0),
    `.medium`(12t, r 1.5), `.large`(16t, r 2.0), `.grand`(24t, r 3.0);
    `var teeth: Int`, `var radius: Double` (hole units), `var metal: MechMetal`.
  - `struct BenchGear: Identifiable` — `id`, `col`, `row`, `size`,
    `var omega: Double`, `var jammed: Bool`.
  - `struct BenchBoard` — `cols: Int = 7`, `rows: Int`, fixed
    `motor: (col: Int, row: Int)` + `motorSize: BenchGearSize = .medium`;
    `outputs: [(col: Int, row: Int)]` (for challenges);
    `mutating func place/remove`, `func solved() -> [BenchGear]` (the solver),
    `var isJammed: Bool`, `func omegaAt(col:row:) -> Double?`.
- Solver algorithm (BFS from motor, ω per mesh):

```swift
// mesh test in hole units:
func meshes(_ a: BenchGear, _ b: BenchGear) -> Bool {
    let d = hypot(Double(a.col - b.col), Double(a.row - b.row))
    return abs(d - (a.size.radius + b.size.radius)) <= 0.18
}
// BFS: motor ω=+1·speed; neighbor ω = -ω·Double(g.teeth)/Double(n.teeth).
// If a gear is reached twice with |ω1-ω2| > 0.01·max(|ω1|,1) → board jammed:
// every connected gear gets omega 0, jammed=true.
```

- [ ] Implement file; hand-verify ratio table in comments (8→16 teeth: ω×0.5 opposite; 24→8: ω×3; triangle 8-8-8 with odd loop → jam).
- [ ] DEBUG-only `benchSolverSelfTest()` (asserts the table above) called from app init under `COG_SELFTEST=1` env.
- [ ] Compile + run self-test on sim (env hook), expect "BENCH SELFTEST OK" in console; commit "feat: bench mesh solver".
